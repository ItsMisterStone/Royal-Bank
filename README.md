# CSE115-Lab-Project

------------
Introduction
------------
This is the "Bank transaction program" created by me for the project of CSE115 Lab.

------------
What it does
------------
The program currently has carries out 3 main tasks after showing the splash screen and login. Firstly you can check your balance stored in either you savings or your current account. Then you can chose if you want to deposit or withdraw cash from the given accounts. The program will close once the user has decided to quit.

------------
How it works
------------
The program consists of 4 program files and 7 text files. They are as follows:

(1) main.c | This carries out the functions of the other header files and runs the main program.
(2) splash.h | This shows the splash screen at the start of the program.
(3) login.h | This exexutes the login process of the system.
(4) mehu.h | The rest of the program and menu is run in this file.

(1) Royal Bank Words.txt | This contains the characters of the title of the bank used in the program.
(2) Royal Bank Logo.txt | This contains the logo icon of the bank used in the program.
(3) Usernames.txt | This contains the usernames of the users of the program.
(4) Passwords.txt | This contains the passwords of the users of the program.
(5) Pins.txt | This contains the pins of the users of the program for extra security.
(6) Savings Accounts.txt | This contains the cash amount of each savings account of the users.
(7) Current accounts.txt | This contains the cash amount of each current account of the users.
